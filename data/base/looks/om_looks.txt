# OpenMerc GFX-modern r_om_look: the colour of the picture (gl3_look.c)
#
# The picture is graded in float at the end of the view, as a film camera; SoF's 8-bit colour table stays neutral.
# Edit this file (a copy in the game folder, openmerc/looks/om_looks.txt, overrides the one in the pak) and type
# r_om_looks_reload in the console. r_om_camera 0..1 (menu: Film Camera) blends from the plain picture to the camera;
# r_om_look_preset <name> forces a grade on every map; r_om_look 0 brings back the original colour table
# (renderer restart).
#
# grade <name> <ev> <temperature> <tint> <saturation> <contrast> <vignette> <grain> [lut]
#   ev           exposure in stops (-0.5 = a third darker)
#   temperature  white balance: > 0 warm (sun, lamps), < 0 cold (night, snow); about -1..1
#   tint         > 0 towards magenta, < 0 towards green; about -1..1
#   saturation   1 = as is, 0.8 = muted
#   contrast     around mid grey: 1 = the film curve as is, below 1 opens the shadows (SoF maps are dark)
#   vignette     darkening towards the corners (0..1), grain: film grain (0.01 = fine)
#   lut          optional strip of N slices of N x N (looks/neutral_lut.png graded in an image editor)
# map <map name, '*' allowed> <grade>      the first matching line wins
