# OpenMerc GFX-modern r_om_ssr: material table (gl3_material.c)
#
# What the world faces are made of and how they reflect. Edit this file (a copy in the game folder,
# openmerc/materials/om_materials.txt, overrides the one in the pak) and type r_om_materials_reload in the
# console; r_om_material prints the texture, SoF material and class of the face under the crosshair.
#
# class <name> <refl> <rough> <walls> <ceil> <detail> <stain> <damp> <soak>
#   refl    reflectivity on floors (0 = matte, 0.9 = mirror)
#   rough   roughness of the reflection (0 = sharp, 1 = blurred away)
#   walls   factor on walls, ceil factor on ceilings (floors 1)
#   detail  how much the texels decide (dark grout, cracks, grime and gritty patches are dull; for glass:
#           only the panes of a painted window, not its frame, sill or the wall around it)
#   stain   how much rust and dirt colours dull the surface
#   damp    natural dampness without rain (sewers, catacombs), scaled by r_om_ssr_damp
#   soak    how much rain water it holds: 1 puddles and wet sheen, under 0.5 no puddles, 0 only darkens
# The first 20 classes have fixed numbers (picture, liquid and mirror are handled specially); up to 4 more
# can be added. A class line overrides the built-in values.
#
# tex <texture> <class>     texture as textures/<set>/<name> without the extension; '*' matches anything.
# A texture missing from the table is sorted by the built-in rules (name, SoF material, detail texture).
# The table below was sorted from the name, the SoF surface material, the artist's detail texture
# (d_stonerough, d_metalsmooth, d_tile, env maps) and the share of rust colours in the texture.
