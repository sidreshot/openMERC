# OpenMerc data (`base\zz_openmerc.pak`)

OpenMerc's own game-data files, GPL like the code. They mirror the pak layout (`data/base/menus/...`,
`data/base/strip/...`) and are packed by `data\build.cmd` (`tools\mkpak.py`) into
`<build dir>\release\zz_openmerc.pak`; `tests\X1\assemble.ps1` copies the archive next to the stock paks.

Why an archive: loose files in `base\` rank below every archive (SPEC-300), so replacement pages must come
from an extra `.pak`; extra archives are scanned after `pak0..pak9` in directory order, `zz_` sorts after
`zmain`/`zsond`, and the name does not end in `PAK<digit>.PAK`.

No file of the original game is ever placed here (CLEANROOM.md). Pages reuse stock string references
(`^MENU_VIDEO_RESOLUTION^` ...) so localised installs keep their language for them; new concepts have
their own package `strip/menu_omvideo.sp` (ID 199, English in every slot).

| File | Content | Package |
|---|---|---|
| `menus/m_video.rmf` | the video page on the engine's real settings | V1 (docs/impl/V1.md) |
| `menus/video.cfg`, `menus/applyvid.cfg` | staging (`menu_*`) on opening the page, applying on Apply | V1 |
| `default_video.cfg` | the Defaults button: OpenMerc's desktop defaults | V1 |
| `strip/menu_omvideo.sp` | labels of the new rows (ID 199) | V1, MENU2 |
| `menus/m_audio.rmf`, `m_keys.rmf`, `m_misc.rmf`, `m_scale.rmf`, `m_options.rmf` | audio, controls, mouse/movement, gameplay pages and the settings tabs | MENU2 (docs/impl/MENU2.md) |
| `menus/m_video_s3tc.rmf` | empty replacement of the S3TC fragment | MENU2 |
| `menus/login.rmf`, `menus/f_login.rmf` | multiplayer login page | MENU2 |
| `default.cfg`, `configs/DEFAULT_KEYS.cfg` | start-up defaults: modern controls, always run, free look | MENU2 |
| `strip/menu_omovr.sp` | own wording that replaces stock texts (`OMOVR_<reference>`, ID 196) | MENU2 |
| `strip/menu_omset.sp` | texts of the new settings rows (ID 197) | MENU2 |
| `strip/menu_ompg.sp` | texts of the own folder pages, dialogs and key actions (`MENU_OMSET_PG_*`, ID 201) | MENU-SCRATCH |
| `strip/menu_omfill.sp` | texts for references no stock package defines (`OMFILL_<reference>`, ID 198) | MENU2 |

The `.sp` packages are generated by `tools/menu2/gen_strings.py` (English and Russian, written from scratch).
