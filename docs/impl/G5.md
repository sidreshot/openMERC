## Black-box findings (also in OPEN_QUESTIONS, G5)
- The "bot flag" of SPEC-741 3 is **server flag 0x200**: with it, the original engine silently drops sends to the
  bot's client slot (SP_Print to the entity, welcome print); without it the first such send stops the server
  with `SZ_GetSpace: overflow without allowoverflow set` (bisected over server-flag bits 0x100…0x80000000; entity
  flags do not matter). This answers SPEC-001's "UNVERIFIED which entity flag".
- Bot removal (`set bot_name0 ??????` by rcon, oracle): svc_sp_print 0x0C04 (`%s disconnected`) and configstring
  1415+slot emptied; no plain print.
- Fill timing: the request made by the fill step is served in the same frame (exact 1.5 s spacing).

## Interpretations (spec silent; revisit when answered)
- Noise record kind: the kind of the latest noise; loudness the maximum within the 1 s window.
- Fire-time fields of a bot's user command: level time when the button is pressed.
- Item selection for the medkit/grenade rules: `itemnext` until the selected type matches; a selected grenade or
  flash pack is thrown with `itemuse` at the next fire of the normal fire control.
- Move-point finish with |m|² < 0.1: the unnormalised move vector is stored as the last direction.
- Cone helper with equal radii (original divides by zero): treated as a cylinder.
- Hidden spawn "free" test: any in-use entity in the solid area list within 100 units counts.
- Roaming "remembered way": the waypoint the bot came from.
- Stuck rule "when the waypoint is a jump waypoint": taken as the previous (left) waypoint being kind 2.
- Editor: wall-clearing and floor traces use mask 3; collinear pruning restarts a node's scan after each removal;
  the version-10 `.nav` block is read after the second node set; link statistics "unable to find each other",
  "invalid looping paths" and "average nodes" are printed as 0.
