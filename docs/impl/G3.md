## Public interface
`game/src/damage/damage_api.h` (documented at the top). G2 (`ai/ai_api.h`) and G4 (`roster/`) already build on it.
- Damage: `Dmg_Damage` (12 values), `Dmg_RadiusLinear/MinMax/Cone`, `Dmg_CanDamage`, `Dmg_CharacterDamage`
  (default `G3BodyOwner::Damage`), shot hit list `Dmg_ShotTrace` / `Dmg_ShotFilter` / `dmg_shot`.
- Bodies: `Body_Create(ent, family)`, `G3Body` (playback, choices, damage, set-up requests, voices, weapons),
  `G3BodyOwner` (what the body asks the AI), animation tables `g3_humanAnims` (539) / `g3_dogAnims` / `g3_cowAnims`.
- Gore: `Gore_ReadLocks`, `Gore_LevelStart`, `Gore_DekkerSplit`; vehicle/heli helpers `Body_Heli*`, `Body_Vehicle*`.
- Cross-package hooks `g3hooks` (all optional, NULL = built-in default).
