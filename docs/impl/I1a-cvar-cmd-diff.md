# I1a: cvar and command lists of OpenMerc compared with the original 1.07f

Black-box comparison (SPEC-302 test vector 8 / SPEC-301 test vector 7). Original: console logs of a plain start of
the original client and dedicated server (`openmerc-data/oracle/*_cvarlist_cmdlist.log`). OpenMerc: the I1a build
(engine core on HEAD 77bd563, without the uncommitted work of other packages), started with
`-portable -basedir D:/Games/SoF-test-I1a +set user <dir> +set vid_fullscreen 0 +set logfile 2 +cvarlist +cmdlist`.
Tables generated by `tools/diff_cvarcmd.py`; the expected-missing groups use SPEC-302's "Registered by" column.

The same comparison on the shared working tree of 2026-10-22 09:40 (I1a together with the uncommitted I1b, I3, I5,
I6h, I6m work) gives client cvars 504 / 586 (399 identical, 64 missing = renderer internals and game), client
commands 239 / 247 with only 19 missing: `gsc_*` (13), `joy_advancedupdate`, `avi`, `rawshot`, `vid_front`, `ping`,
`serverstatus`. The 60-command console probe gives the original's text there too, except `gserver test`
(original `Ghoul :Test is Off`, OpenMerc `Test is Off`, Ghoul debug interpreter of I3/I1b).

Reading the differences:
- **Missing cvars**: only renderer internals (62, the original `ref_gl.dll` registers them; OpenMerc's renderer is
  I4a's) and 2 game-module cvars. No engine cvar of SPEC-302 is missing.
- **Flags differ** (client 20, dedicated 1): renderer cvars the original renderer registers as archived and that
  OpenMerc only gets as plain cvars from `default_video.cfg`; `dmflags`, which the game module registers.
- **Value differs**: the renderer's driver configs (`drivers/alldefs.cfg`, `<card>.cfg`, `memory<n>.cfg`,
  `cpu<n>.cfg`, executed by the original renderer at start: `cl_max_debris`, `cl_max_quads`,
  `fx_maxdebrisonscreen`, `win_*`, `vid_gamma`, `ghl_light_method`), the test setup (`user`, `basedir`, `logfile`,
  `ip`, `vid_fullscreen`), the random `qport` and the measured `cpu_speed`.
- **Extra cvars / commands**: the Yamagi base (client `cl_*`, gyro/joystick, GL3 `gl3_*`/`r_*`, server `sv_*`,
  `coop`, Quake II menus `menu_*`, `download`, `packet`, `gun_*`), Yamagi main-loop cvars `busywait`, `cl_async`,
  `vid_maxfps`, and the OpenMerc diagnostics `om_strings`, `om_savecheck`, `om_delay` (docs/DEVIATIONS.md).
- **Missing commands**: GameSpy chat `gsc_*` (13; optional, the chat servers are gone), menus (17, I6m), force
  feedback (4), effects editor `fx_load`/`fx_save` (I5), `terrain`/`cloud`/`joy_advancedupdate` (I6h), `vid_front`,
  `avi`/`rawshot` (renderer), and 9 client commands: `ignore`, `unignore`, `listignore`, `addfave`, `remfave`,
  `cl_touch` (implemented by I6h in the shared tree, not in this build), `ping`, `serverstatus`, `reset_predn`
  (behaviour not specified, OPEN_QUESTIONS I1a 7).
