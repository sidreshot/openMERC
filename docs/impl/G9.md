# G9 — game modes and Ghoul glue

Implementation journal (C team). Specs: SPEC-790 (game modes), SPEC-791 (game-side Ghoul glue); with SPEC-780/781/782
(G18), the ERRATA corrections from SPEC-790 and SPEC-AMEND-005 items G9.1–G9.11.

## Published interfaces (other packages: code against these)
- `game/src/ghoulglue/gg_ghoul.h` — SPEC-791 Ghoul glue: model records `GGModel`, object instances `GGInst`,
  bolt-ons `GGBolt`, skins/sequences/availability, `GG_SetSimpleModel`, name helpers, attached-object records
  `GGAttached` (props, G7), placement helpers, aim controller `GGAim`, savegame chunks (AI-table kinds, GGOB/GGON/
  STRG, GGOI/GHLI, GGBI/GHLI, EDOI/EDBN/EDBL, id remap), `ghoul_model` test entity. G18 (`g_ghoul.cpp`,
  `g_pmodel.cpp`), G3, G4 and G7 use it. Never call `GhoulRemove`/`Destroy` on an instance that came from the glue.
- `game/src/modes/g_modes.h` — SPEC-790 game modes: mode/flag queries (`GM_DMFlags`, `GM_Flag`, `GM_TeamPlay`,
  `GM_SameTeam`, `GM_Team`, ...), the hooks the game core calls (list at the top of the header), rule queries for
  items/weapons/damage, scoreboards and status layouts, CTF/Control flag rules (SPEC-781 9/10), Conquer zones, and
  the state the bots need (below). G9 installs G5's `Bot_SetModeHooks` and G3's `g3hooks` (dmflags, sameTeam,
  dmPlayerHit, modelObject) at every level start.
- G5 (bots), done 10-25: `GM_CTFFlagTeam`, `GM_CTFBaseFlag`, `GM_CTFFlagAtBase`, `GM_CarriedFlag`,
  `GM_ControlOwner`, `GM_InConquerZone`, `GM_AssassinTarget`, `GM_Exhausted`, `GM_Team` are public; the hooks of
  `BotModeHooks` are filled from them.

- Build: cmd.exe `set OM_BUILD_DIR=<repo>\build-G9-x86` then `game\build.cmd Release`.
